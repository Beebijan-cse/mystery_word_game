# Mystery Word Game

A beginner-friendly command-line game written in Python. Guess the hidden word one letter at a time. After an incorrect guess, the game shows a hint.

## Features

- Randomly selects a word and its hint
- Shows the number of letters in the word
- Reveals correctly guessed letters
- Gives a hint after an incorrect guess
- Allows up to seven incorrect guesses
- Rejects invalid and repeated guesses
- Lets you play another round

## Requirements

- Python 3
- No external packages

## How to Run

Open a terminal in the project folder and run:

```bash
python mystery_word_game.py
```

## How to Play

1. Enter one English letter from A to Z.
2. Correct guesses reveal letters in the word.
3. Incorrect guesses use one attempt and show a hint.
4. Guess the word before you run out of attempts.
5. Choose whether to play another round.
